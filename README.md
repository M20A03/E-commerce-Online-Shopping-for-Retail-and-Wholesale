Full-stack hybrid retail and wholesale commercial platform with tiered volume pricing, QR-code payment generation, Framer Motion animations, and Firebase cloud persistence.

## ✨ Key Features

- **Dual Retail & Wholesale tier pricing engine with minimum quantity bulk thresholds**
- **Instant dynamic UPI & digital invoice QR code generator (`qrcode.react`)**
- **Framer Motion spring physics for card hovers, cart draws, and modals**
- **Firebase Authentication and Firestore real-time inventory management**
- **Cookie-backed session persistence with instant local state synchronization**

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher) / Python 3.10+ (where applicable)
- Git installed on your system

### Installation & Run

```bash
git clone https://github.com/M20A03/E-commerce-Online-Shopping-for-Retail-and-Wholesale.git
cd E-commerce-Online-Shopping-for-Retail-and-Wholesale
npm install
npm run dev
```
