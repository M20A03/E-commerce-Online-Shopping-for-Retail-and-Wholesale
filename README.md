## Key Features

- **Dual Retail & Wholesale pricing:** Tier pricing engine with minimum quantity bulk thresholds.
- **Dynamic UPI invoice generation:** Instant QR code generator for direct merchant payment.
- **Fluid transitions:** Spring physics for cart drawers and modal views.
- **Firebase Authentication & Firestore:** Real-time inventory synchronization.
- **Session persistence:** Instant local state synchronization across browsing sessions.

---

## Spatial Web and Mobile Viewport Specifications

- **Precision Viewport Scaling:** Strict mobile viewport tuning with safe-area insets, 48px touch targets, and fluid 2-column masonry grid for flagship devices.
- **Touch Ergonomics:** Standard 48px minimum interactive tap boundaries across all buttons, inputs, and navigation drawers.
- **Hardware Acceleration:** Zero image-layout shifts, GPU-accelerated micro-animations, and fluid 60fps transitions.
- **Safe Area Inset Handling:** Dynamic insets utilizing `padding-bottom: max(16px, env(safe-area-inset-bottom))`.

## Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- Git installed on your system

### Installation and Run

```bash
git clone https://github.com/M20A03/E-commerce-Online-Shopping-for-Retail-and-Wholesale.git
cd E-commerce-Online-Shopping-for-Retail-and-Wholesale
npm install
npm run dev
```
